### 🚀 Proyectos destacados

#### 🧾 NOVUS POS — punto de venta e inventario para PYMES

[![NOVUS POS — punto de venta con escáner y pagos](https://raw.githubusercontent.com/987rafa/novus-pos/main/docs/shots/03-pos.png)](https://github.com/987rafa/novus-pos)

**[NOVUS POS](https://github.com/987rafa/novus-pos)** — sistema full-stack de punto de venta e inventario para negocios pequeños (tiendas, panaderías, minimercados), con interfaz en español:

- 🛒 Ventas con carrito, descuentos e IVA 19 % automático · anulación con reposición de stock
- 🏷️ Escáner de código de barras (lector USB) y fotos de producto
- 💳 Efectivo (con recibido y cambio), transferencia o tarjeta · recibo imprimible
- 💰 Turnos de caja: apertura con base, arqueo al cierre e historial de diferencias
- 📥 Pedidos entrantes (WhatsApp / web) → la caja los confirma como venta en un clic
- 📊 Dashboard en tiempo real · un administrador (el dueño) y cajeros vinculados a él
- 🐳 React 19 · FastAPI · PostgreSQL · Docker Compose · 66 tests · MIT

#### 🤖 WhatsApp AI Agent — un asistente que atiende tu WhatsApp

[![whatsapp-ai-agent](https://raw.githubusercontent.com/987rafa/whatsapp-ai-agent/main/assets/banner.svg)](https://github.com/987rafa/whatsapp-ai-agent)

**[whatsapp-ai-agent](https://github.com/987rafa/whatsapp-ai-agent)** — agente de IA self-hosted para WhatsApp:

- 🤖 Responde tus mensajes de forma autónoma (sabe con quién habla)

- 🛒 Toma pedidos para tu negocio (`!menu` + `!pedido`) y los manda al panel de Pedidos de [NOVUS POS](https://github.com/987rafa/novus-pos)
- 🔔 Te avisa cuando un mensaje necesita a una persona real
- 🔒 Gemini (capa gratuita) o 100% local con Ollama · Docker · MIT

#### 🧭 Job Copilot — copiloto de postulaciones con IA

[![Job Copilot — panel con métricas y seguimientos](https://raw.githubusercontent.com/987rafa/job-copilot/main/docs/shots/panel.png)](https://github.com/987rafa/job-copilot)

**[Job Copilot](https://github.com/987rafa/job-copilot)** — copiloto que ordena tu búsqueda de empleo de punta a punta:

- 🎯 Analiza la oferta frente a tu CV: encaje 0–100, fortalezas, brechas y palabras clave
- ✍️ Redacta carta, mensaje y seguimiento listos para copiar (español/inglés, 4 tonos)
- 🗂️ Tablero kanban: guardada → aplicada → entrevista → oferta / rechazada, con notas y fechas de seguimiento
- 📊 Panel con métricas, gráfico por estado y próximos seguimientos · CV en PDF o TXT
- 🧠 IA intercambiable: cualquier API compatible con OpenAI, Gemini, o motor heurístico local sin claves
- 🐳 React 19 · FastAPI · SQLite/PostgreSQL · Docker Compose · 32 tests · MIT
